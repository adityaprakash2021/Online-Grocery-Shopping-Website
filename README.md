# Online-Grocery-Shopping-Website
A dynamic shopping cart web application built with **Flask**, **HTML**, **CSS**, and **JavaScript**.  
It allows users to select items, view prices in real-time, and place orders with a clean, responsive UI.

---

## 🚀 Features

- ✅ Real-time price calculation
- ✅ Stylish product cards with bold, black item names and prices
- ✅ Transparent container over background image
- ✅ “Order Again” button to reset selections
- ✅ User-friendly form interface
- ✅ Flask backend with Jinja2 templating

---

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript  
- **Backend**: Python Flask  
- **Templating**: Jinja2

---

## 📸 UI Highlights

- Bold, black fonts for better visibility  
- Grid layout for product display  
- Real-time price updates as items are selected  
- Transparent form container on themed background
